# RAIFKA

Static participant project site for the Next Gen Lab concept. The site is a bilingual experience in Czech and English with a vertical feed, team section, motivation section, FAQ, posters, photos, and video assets.

## Project Structure

- `web/` - main website files
- `poster/` - poster assets
- `profile_photos/` - team photos
- `videos/` - video assets used in the feed

## How To Run

1. Open `web/index.html` in a browser, or
2. Serve the `web/` folder with any local static server.

## Notes

- The page supports switching between Czech and English.
- Video links and content are wired from `web/script.js`.
